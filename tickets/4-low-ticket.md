## Resolution Steps

1. Received and read the ticket then identified three distinct changes required, not just a simple name update.

2. Searched user directory for “Amanda foster” to locate account.

3. Verified user identity by cross-referencing username (afoster), department (Finance), and Employee ID (EMP-4127) against ticket details before making any changes.

4. Selected Change Name and Email from the user profile.

5. Update the display name to Amanda Reyes.

6. Update the primary email to areyes@servicedesk-simulator.com.

7. Added afroster@servicedesk-simulator.com as an email alias, ensuring all existing email threads and replies remain accessible to the user.

8. Saved changes and confirmed updates applied correctly.

9. Closed the ticket with clear resolution notes for the audit trail.

## Key Skills Demonstrated

- User account administration in a directory system

- Identity verification before making account changes

- Email alias management-preserving continuity for the user

- Attention to detail - correctly identifying all three required changes from one request

- Clear resolution documentation for audit trail purposes

- Low-priority ticket managed efficiently without unnecessary escalation.

## What I Learned
This ticket demonstrated that a seemingly simple name change request can involve multiple interdependent changes: display name, primary email, and alias configuration. Missing any one of these would have caused disruption for the user. In a real environment, this type of change would typically require verification of HR approval before proceeding, which was confirmed in the ticket itself. Identity and access management tasks require careful reading of the full request before acting.
